# Relation to the certificate

The projects were built alongside the IBM Generative AI Engineering Professional Certificate
(Coursera, 16 courses, completed August 2026). The table says which courses each project draws
on, by number and public catalogue title. No course material is in this repository.

| Project | Courses drawn on | Technique shown |
|---|---|---|
| P01 mini-ETL | 4 Python for Data Science, AI & Development · 7 Data Analysis with Python | pandas cleaning, imputation, multi-format export |
| P02 question bank | 4 Python for Data Science, AI & Development | parsing, validation, JSON Schema |
| P03 regression | 8 Machine Learning with Python | linear regression, evaluation, coefficients |
| P04 decision tree | 8 Machine Learning with Python | classification, stratified split, rule export |
| P05 segmentation | 8 Machine Learning with Python | K-Means, silhouette, PCA |
| P06 ML pipeline | 8 Machine Learning with Python | Pipeline, GridSearchCV, model card |
| P07 sentiment API | 5 Developing AI Applications with Python and Flask | Flask JSON API, pure function, tests |
| P08 image captioning | 6 Building Generative AI-Powered Applications with Python | BLIP, Gradio, batch inference |
| P09 chatbot | 6 Building Generative AI-Powered Applications with Python | Hugging Face seq2seq, Flask, history window |
| P10 meeting assistant | 6 Building Generative AI-Powered Applications with Python · 3 Generative AI: Prompt Engineering Basics | Whisper → LLM chain, provider seam |
| P11 RAG chatbot | 15 Fundamentals of AI Agents Using RAG and LangChain · 16 Project: Generative AI Applications with RAG and LangChain | loaders, splitters, embeddings, Chroma, a grounded retrieval-QA chain |
