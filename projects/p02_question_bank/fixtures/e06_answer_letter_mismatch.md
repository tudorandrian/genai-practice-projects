## 3. Practice Questions

### Q1. (Multiple Choice)
Which component of a CSV parser is responsible for turning a raw delimiter-separated line into typed field values?

- A) The tokenizer — **Incorrect.** It only splits the line on the delimiter.
- B) The type coercer — **Correct answer.** It converts each raw token to its target type.
- C) The line buffer — **Incorrect.** It only holds unread bytes.

- **Answer:** C
