### Q1. (Multi-Select)
Which of the following are TRUE about tokenizers and parsers? (Select two.)

- A) A tokenizer can emit tokens without knowing the full grammar. - **Correct answer.** Rationale.
- B) A tokenizer always requires a symbol table to run. - **Incorrect.** Rationale.
- C) A tokenizer's output stream is the parser's input. - **Correct answer.** Rationale.
- D) A tokenizer must execute the grammar's semantic actions. - **Incorrect.** Rationale.

- **Answer:** A, C
