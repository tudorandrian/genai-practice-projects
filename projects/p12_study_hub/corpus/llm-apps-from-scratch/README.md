# LLM Apps from Scratch

A ten-lesson course on building a small, local-model-powered application end to end, following a fictional documentation assistant, Pebble, built for Fenwick Labs: prompting, serving, tokenization, retrieval-augmented generation, evaluation, cost trade-offs, and safety guardrails.
