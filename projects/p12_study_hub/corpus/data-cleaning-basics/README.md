# Data Cleaning Basics

A ten-lesson course on cleaning a messy, realistic tabular dataset end to end, using the trip log of a fictional bike-share operator, Wheel & Way, as the running example. Covers sentinel values, type coercion, duplicates, outliers, imputation, text normalization, timestamp parsing, validation, and export.
